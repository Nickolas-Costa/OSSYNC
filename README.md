# OSSYNC — instaladores

Este repositório só guarda os instaladores do OSSYNC para Windows. O código é privado.

- Baixe o `OSSYNC-Setup-X.Y.Z-x64.exe` da [última versão](../../releases/latest) e execute. Não pede administrador.
- A partir da 2.17.0, o próprio app busca e instala as versões novas (Configurações → Dados e retenção → Buscar atualizações). Ele confere o SHA-256 que o GitHub mostra em cada arquivo.
